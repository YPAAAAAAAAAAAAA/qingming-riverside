# qingming-riverside

A clean-room, from-scratch re-implementation of the idea behind **[xianxie6/qingming-riverside](https://github.com/xianxie6/qingming-riverside)** by [@xianxie6](https://github.com/xianxie6). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
